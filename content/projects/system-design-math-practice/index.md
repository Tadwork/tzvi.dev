System Design Math Practice is a focused practice app for the kinds of math that show up in system design interviews: traffic estimates, storage calculations, bandwidth, latency, and back-of-the-envelope sizing.

The project is live at [system-design-math-practice.tzvi.dev](https://system-design-math-practice.tzvi.dev/) and the source lives in the [GitHub repository](https://github.com/Tadwork/system-design-math-practice).
